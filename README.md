# OpenPuck Web Configurator (with Bluetooth Controls)

Live Website: **[https://adadeane.github.io/openpuck-web/](https://adadeane.github.io/openpuck-web/)**

This is the WebUSB configuration interface for the OpenPuck firmware, featuring wireless Bluetooth (BLE) peripheral controls.

## Features
- **WebUSB Direct Connection**: Configure your OpenPuck board directly from Google Chrome or Microsoft Edge (no drivers needed).
- **Bluetooth Wireless Controls**:
  - Enable / Disable Bluetooth mode.
  - Switch between **Universal BLE HID Gamepad** and **Xbox Wireless Controller BLE** profiles.
  - On-demand Bluetooth pairing trigger.
- **Controller Tuning**: Trackpad-to-stick curves, haptics, stick deadzones, and button remapping.
- **Precompiled Firmware**: Download [irmware/OpenPuck.ino.uf2](firmware/OpenPuck.ino.uf2) directly to flash to any nRF52840 Pro Micro board.
